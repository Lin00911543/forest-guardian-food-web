# 遊戲企劃書｜森林守護隊：食物網行動卡

**版本：** MVP 實作版 v1.1  
**專案類型：** Phaser 4 瀏覽器遊戲  
**企劃狀態：** 素材挑選完成；MVP 首版已實作，族群模型仍需試玩調整

## 一、遊戲概念

玩家是森林保育區管理員，使用保育行動卡處理環境事件，並觀察五種生物之間的食物網變化。每關有一項保育任務；玩家要在有限回合內維持物種數量，完成後重玩同一關，用族群變化圖比較兩種策略，並選出符合資料的原因說明。

遊戲服務國小三、四年級學生，採個人遊玩、2D 像素美術與短回合卡牌策略。根目錄直接啟動遊戲；任務說明是遊戲內的開場，不另做網站首頁。

**暫定名稱：**《森林守護隊：食物網行動卡》

## 二、學習目標

完成遊戲後，學生應能：

1. 閱讀森林食物網，辨認哪些生物提供食物、哪些生物以它們為食。
2. 說明保育行動對目標物種的直接影響，以及食物網中可能出現的連鎖變化。
3. 比較同一關的兩種策略，根據族群變化圖選出較符合結果的原因。

遊戲以學生的原因判斷和圖表證據作為學習表現。完成關卡、遊玩時間或總分只反映遊玩狀況，不單獨代表學會。

## 三、玩家與遊玩情境

- **玩家：** 國小三、四年級；以未深入學習食物網的學生為預設。
- **模式：** 單人瀏覽器遊戲，可重玩同一關。
- **單次遊玩：** 五回合；初步目標約 5–10 分鐘，實際時間於試玩後調整。
- **呈現方式：** 清楚的生物圖示、箭頭、族群數量條和簡短繁體中文說明；不能只用顏色表達安全或危險狀態。

## 四、食物網與遊戲狀態

MVP 先採用一個簡化森林食物網：

```text
植物 → 昆蟲 → 小型鳥類 → 猛禽
  └────────→ 兔子 ─────→ 猛禽
```

箭頭表示食物流向消費者。這五類生物及關係是教學模型；定稿前需核對物種與食性，避免讓簡化規則被誤認為真實森林的完整預測。

MVP 將族群呈現為 0–10 的相對數量指標，而非真實個體數。每關設定各物種的安全範圍、起始數量、任務條件和固定事件序列。數值、範圍和模擬係數先作為可調資料，不在企劃階段假裝已經平衡完成。

模擬採可解釋的確定性規則：環境事件和卡牌先直接改變目標物種，再用同一份結算快照同時計算食物網連鎖變化，避免計算順序改變結果。回合結算分別標示事件效果、卡牌直接效果、食物網推演結果與簡短原因。

## 五、核心玩法

### 一局流程

1. 顯示關卡任務、五種生物的初始族群、安全範圍、食物網和七張保育行動卡。
2. 玩家從七張卡中選五張，安排出牌順序；每回合打出一張，已使用的卡不能重複使用。
3. 每回合揭示一張預設環境事件，再打出一張保育行動卡。事件順序在同一關的兩次遊玩中完全相同。
4. 卡牌對目標物種產生直接效果；之後系統根據食物網推演族群變化，顯示各物種變化和原因。
5. 完成五回合後，判斷關卡任務和安全範圍條件，儲存該次逐回合族群紀錄。
6. 玩家以相同初始數量、事件順序和七張卡重玩，重新選五張卡並安排順序。
7. 並排顯示兩次族群變化圖，玩家選擇最符合圖表的原因解釋。

### 卡牌與事件

MVP 七張牌為森林復育（植物 +2）、昆蟲棲地（昆蟲 +2）、兔類庇護（兔子 +2）、林鳥築巢（小型鳥類 +2）、猛禽棲架（猛禽 +2）、灌木補植（植物 +1）、移除捕獸陷阱（小型鳥類 +1）。卡牌值是可調的原型參數；試玩後檢查每張卡的取捨，避免出現固定選牌就自然通關的情形。

MVP 五回合事件依序為短暫乾旱（植物 −2）、溫暖春天（昆蟲 +1）、強風吹襲（小型鳥類 −1）、兔子繁殖季（兔子 +2）、寒流來襲（猛禽 −1）。每關使用固定事件序列，重玩時不改變，讓學生能把結果差異歸因於選卡和出牌時機。

### 勝敗與回饋

- **勝利：** 五回合結束時植物至少 6 格，且五種生物都在安全範圍 2–8。
- **危機提示：** 族群離開安全範圍時在該生物卡上顯示「低於／高於安全範圍」，仍允許玩家嘗試修正。
- **失敗：** 物種降至 0 時可立即顯示危機結果；五回合結束仍未達成條件時，顯示未達成項目並允許重玩。
- **每回合回饋：** 顯示卡牌造成的直接變化、相關食物網箭頭和連鎖變化；讓學生看出「什麼改變、影響了誰、為什麼」。
- **比較回饋：** 兩次遊玩的折線圖共用相同刻度，標記安全範圍和事件點；問題選項須根據實際圖表編寫，不能只靠背記固定答案。

## 六、美術與素材方向

使用親切、辨識度高的 2D 像素美術，優先挑選可合法使用的現成素材。MVP 素材至少包括：

- 森林背景或地面圖塊。
- 植物、昆蟲、兔子、小型鳥類、猛禽五種圖示或精靈圖。
- 七張保育行動卡的卡面或共用卡框與圖示。
- 族群條、食物網箭頭、事件和關卡任務所需的介面圖示。
- 支援繁體中文字形、授權條件符合專案用途的字型。

MVP 已選用 Kenney Tiny Town 的草地、樹木與灌木圖塊，以及 Clint Bellanger 的 Tiny Creatures 16×16 像素生物圖示；繁體中文字型採 justfont jf open 粉圓 2.1。這些素材的授權文字保存在素材資料夾，完整檔案清單與授權說明見 [`docs/asset-sources.md`](asset-sources.md)。卡框、按鈕、族群條、箭頭和圖表由 Phaser Graphics 繪製。MVP 的小型鳥類圖示以烏鴉／渡鴉代表鳥類群組，視為類別示意，不指定該物種；若後續確定鳥種，替換圖示並同步核對食物網。音效和背景音樂不列為 MVP 阻塞項目。

## 七、實作步驟與迭代

執行順序固定為：**完成素材挑選 → 完成 MVP → 再分階段迭代。**

### 步驟一：完成 MVP 素材挑選

1. 依上述像素美術方向，挑選五種生物、森林背景、卡牌介面、基本 UI 和繁體中文字型。
2. 確認每項素材的授權與署名要求，剔除授權不明或無法用於本專案的素材。
3. 測試素材尺寸、透明背景、色彩可辨識度與中文字型覆蓋。
4. **已完成：** 凍結 MVP 素材組合、保留授權文字並建立素材來源紀錄。素材清單與授權見 [`docs/asset-sources.md`](asset-sources.md)。

### 步驟二：完成可玩的 MVP

1. 建立 Phaser 4 啟動入口，讓根目錄的 `index.html` 直接載入遊戲畫面。
2. 製作一個森林關卡，放入五種生物、食物網、安全範圍、一項保育任務和五張固定順序的事件卡。
3. 製作七張保育行動卡，讓玩家選五張並排列順序；每回合出一張且不能重複。
4. 實作可重複、可解釋的族群推演，回合紀錄包含初始值、卡牌直接效果、食物網變化和結算值。
5. 實作五回合流程、危機提示、勝敗條件、第一次結果保存和同關重玩重設。
6. 製作兩次遊玩的族群變化比較圖，以及根據圖表選擇原因的學習題。

**首版已實作：** 根目錄直接啟動的 Phaser 4 遊戲、七選五且可安排順序的卡牌、五回合固定事件、分開呈現事件／卡牌直接效果與食物網變化、任務結果、同關第二次遊玩、兩次折線圖與解釋題。兩次策略紀錄保存在瀏覽器 `localStorage`，支援重新載入後繼續或查看比較。具體起始數量、事件、卡牌與推演門檻列在本文件第九節；它們是待試玩平衡的第一版設定。

**MVP 完成條件：** 玩家能從根網址直接開始；完成一局並重玩；兩次遊玩的初始狀態、事件序列和卡牌池相同；出牌選擇會造成可觀察的結果差異；每回合能看出直接與連鎖變化；比較圖和原因題確實對應關卡資料。

### 階段一：教學清晰度與模型調整

- 檢查學生是否看懂箭頭、族群條、安全範圍和卡牌效果。
- 依試玩觀察調整族群起始值、安全範圍、事件影響和推演規則。
- 修改原因選項，使學生必須根據圖表和食物網推理，而不是只猜答案。
- 確認每張卡都有可理解的取捨，且沒有單一固定順序可以無條件通關。

### 階段二：增加策略內容

- 為不同關卡加入新的保育任務、起始族群和固定事件組合。
- 根據第一關的平衡結果調整卡牌效果，新增卡牌或卡牌限制。
- 加入逐步增加的食物網複雜度；先讓學生理解現有關係，再加入新物種或新事件。

### 階段三：視覺與可及性完善

- 加入簡短的卡牌動畫、事件轉場和族群變化提示。
- 依需要加入音效與背景音樂，並提供靜音控制。
- 檢查不同視窗尺寸、文字大小、鍵盤操作、色彩辨識和動畫速度。
- 依實際課堂使用回饋調整引導文字與回合節奏。

### 階段四：發布準備

- 確認根網址載入順序、素材路徑、字型、錯誤狀態和重玩流程。
- 完成主要瀏覽器和裝置的操作檢查，確認遊戲紀錄在重玩前後正確重設與保留。
- 更新素材授權紀錄和玩法說明，再決定是否加入更多關卡或課堂教師指引。

## 八、專案目錄對應

沿用已建立的目錄：

```text
index.html                         # 直接啟動 Phaser 遊戲
src/main.ts                        # 遊戲入口與 Phaser.Game 建立
src/game/config/                   # Phaser 設定
src/game/scenes/                   # 載入、森林關卡、結果比較
src/game/entities/                 # 可重用生物或遊戲物件
src/game/systems/                  # 食物網推演、回合與卡牌規則
src/game/ui/                       # 卡牌手牌、族群圖、食物網、比較題
src/game/data/                     # 生物、卡牌、事件、關卡資料
src/styles/                        # 遊戲畫布與全螢幕樣式
public/assets/                     # 已挑選的圖片、字型與遊戲資料
docs/game-proposal.md              # 本企劃書
```

技術預設採 Phaser 4、TypeScript 和 Vite；`index.html` 只承載遊戲啟動所需的頁面結構，開啟後直接進入遊戲內任務說明與關卡流程。模擬規則和關卡資料放在資料／系統模組，不混入場景繪製程式。

## 九、MVP 原型參數與待校準項目

- 採單人、瀏覽器、森林單關作為 MVP；其他模式依後續需求再增加。
- 每關五回合、同一固定事件序列；兩次遊玩使用相同起始狀態和七張卡。
- 起始數量（0–10 相對指標）：植物 6、昆蟲 4、兔子 4、小型鳥類 3、猛禽 2；目前五類生物的安全範圍都設定為 2–8。
- 食物網推演以事件和卡牌結算後的同一快照判斷：昆蟲或兔子至少 6 格時植物 −1；昆蟲與兔子都不超過 2 格時植物 +1。植物至少 7 格時昆蟲與兔子各 +1；植物不超過 3 格時兩者各 −1。昆蟲至少 6 格時小型鳥類 +1；不超過 2 格時小型鳥類 −1。兔子與小型鳥類合計至少 10 格時猛禽 +1；合計不超過 4 格時猛禽 −1。每項變化最多一格，結果限制在 0–10。
- 勝利任務為五回合後植物至少 6 格且所有生物在 2–8；任一物種降到 0 時提前結束並判定失敗。
- 食物網是為三、四年級教學而簡化的模型，應清楚標示並核對內容正確性。
- 第一版不加入多人連線、排行榜、帳號、複雜經濟系統或多關卡，以保留對策略比較的注意力。
- 以上係數與卡牌值尚未經學生試玩平衡；下一步應觀察學生是否能理解直接效果與連鎖原因，再調整門檻和任務難度。
