## 素材選用與限制

- Tiny Town 提供 16×16 草地、樹木與灌木圖塊；MVP 以這些小圖塊排列森林裝飾，沒有使用一張完整森林背景圖。
- Tiny Creatures 的蜂、兔、鷹與烏鴉／渡鴉圖示提供一致的 16×16 像素風。MVP 用鳥類圖示代表食物網中的「小型鳥類」群組，圖示不代表該群組只有烏鴉一種物種；若後續定稿指定確切鳥種，應替換成相符插圖。
- 粉圓字型用於繁體中文遊戲文字；授權檔與字型一同保留。
- 遊戲按鈕、卡框、族群數量條、箭頭與比較圖由程式繪製，不依賴第三方 UI 套件。
